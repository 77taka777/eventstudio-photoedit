対応形式・解像度・保存について

解像度の意味：このツールは縦横のピクセル数を揃えるものです。印刷用のDPI / PPIや、ファイル容量を同じにするものではありません。最大画像は、読み込めた全画像（サブフォルダを含む）の総画素数で決まります。同数の場合は一覧の先の画像を使います。縦画像を自動で横向きに回転させることはありません。

入力：JPG / PNG / WebP / AVIF / BMP / GIF（ブラウザが読み込めるもの）。GIFなどのアニメーションは最初のフレームを静止画として扱います。HEIC / RAW / TIFF / SVGは対象外です。EXIFの向きは読み込み時に反映します。撮影日時・GPS・EXIFや元のICCプロファイルは引き継がず、ブラウザのsRGBキャンバスで再保存します。

出力：JPG / PNG / WebP。JPGは透明非対応のため、透明背景はPNGまたはWebPで使ってください。PNGでは保存品質スライダーは使いません。出力形式がブラウザで非対応の場合は、PNGで保存して画面に知らせます。

大きさの制限：出力は一辺16,000px以内、総画素数80MP以内。入力は一度に最大1,000枚。元画像が120MPを超える場合は対象外にします。画像は1枚ずつ処理しますが、PCやブラウザのメモリにより、この上限未満でも処理できない場合があります。変換済みデータが合計750MiBを超える場合は途中で止めます。その分を保存してから、少ない枚数に分けてください。

データの扱い：画像処理にネット通信・外部ライブラリ・画像のアップロード・ログインは使用しません。公開ページを開く際は、サイトのHTML・CSS・JavaScriptなどを配信元から読み込みます。元ファイルは読み込むだけで上書きしません。「アップロード」と書かれたフォルダ選択ダイアログでも、サーバーには送信しません。別ページへの移動・再読み込み・タブを閉じる操作で、選択と変換結果は消えます。

PC版 Edge / Chrome 向けです。公開ページの読み込みにはネット接続が必要です。
通信のない会場では、事前に「オフライン版を保存」してください。
本番素材は、保存した画像を一度開いて、縦横・切り抜き・見た目を確認してください。
